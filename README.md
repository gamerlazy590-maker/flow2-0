# Flow 2.0 — Free AI Image & Video Generator (Vercel version)

Flow 2.0 is a free AI image & video generator web app:

- **Text-to-Video** — 5 free video generations per day (rolling 24-hour window),
  rendered as real 8-second video clips (camera move over an AI keyframe).
- **Text-to-Image** — unlimited free image generations.
- Accounts with salted-hash passwords, per-user creations library, and an
  admin dashboard for the site owner (the first registered account).

Canonical deployment: **https://flow2-0.vercel.app**

> **This is the Vercel-compatible rebuild.** The previous version of Flow 2.0
> was built for a proprietary runtime and could not deploy on Vercel (its
> build failed on a `file:` dependency that only existed on the original
> build machine). This version is a plain static site — Vite + React +
> TypeScript, only npm-published packages, no server, no environment
> variables, no API keys.

## How it works (and the honest limits)

- **Images:** generated by the free, no-key Pollinations image API
  (`https://image.pollinations.ai`). No API key, no account, no cost.
- **Videos:** an 8-second camera move (zoom in/out, pan left/right) animated
  over the AI-generated keyframe in your browser, played on canvas and
  exported as **WebM** via MediaRecorder. This is an image-based camera
  move, **not real AI motion** — real AI motion video needs a paid
  text-to-video API, which this free build does not include. WebM plays in
  every modern browser and converts to MP4 in any free video editor. MP4
  export was deliberately not faked with an unreliable ffmpeg.wasm bundle.
- **Accounts & credits:** stored **only in your browser's localStorage**.
  Passwords are salted PBKDF2-SHA256 hashes (WebCrypto, 100,000 iterations)
  — never plain text, never sent to a server, because there is no server.
  The first account registered in a browser becomes that browser's
  owner/admin. Accounts and creations are **not synced** between devices or
  browsers, and clearing browser data deletes them. The app says this in
  the FAQ, the Profile tab, and the Privacy Policy.
- **Admin dashboard:** shows every account registered in the same browser,
  with totals, video credits used, and total images.

## Deploy it yourself: GitHub → Vercel (step by step)

You need two free accounts: [GitHub](https://github.com) and
[Vercel](https://vercel.com) (sign in to Vercel with GitHub). No credit card
and no environment variables are required.

### Step 1 — Push this project to GitHub

The repo already exists: **https://github.com/gamerlazy590-maker/flow2-0**
(public). It currently holds the old, non-deployable code — replace its
contents with this project (delete the old files first, or push with
`git rm -r .` then add these files). From inside this folder:

```bash
git init
git add .
git commit -m "Flow 2.0 — Vercel-compatible rebuild (static Vite + React)"
git branch -M main
git remote add origin https://github.com/gamerlazy590-maker/flow2-0.git
git push -u origin main --force
```

(Use `--force` only because the old code is being replaced wholesale; for
later updates, plain `git push` is enough.)

### Step 2 — Import the repo in Vercel

1. Go to https://vercel.com/new (or Dashboard → **Add New → Project**).
2. Under **Import Git Repository**, find **`gamerlazy590-maker/flow2-0`**
   and click **Import**. (If it isn't listed, click "Adjust GitHub App
   Permissions" and grant Vercel access to the repo.)
3. **Project Name:** `flow2-0` — this is what gives you the
   `flow2-0.vercel.app` subdomain. (The project already exists in the
   team `gamerlazy590-1274`; importing the updated repo triggers a fresh
   deployment automatically.)
4. **Framework Preset:** leave as detected / "Other". `vercel.json` already
   declares everything Vercel needs:
   - Build command: `npm run build`
   - Output directory: `dist`
   - SPA rewrites for `/studio` and `/admin`, plus security headers.
5. Root Directory: `./` (the repo root).

### Step 3 — Environment variables

**None required.** Leave the Environment Variables section empty.

### Step 4 — Deploy

1. Click **Deploy** and wait for the build to finish (about 1–2 minutes).
2. Vercel shows your live URL: **https://flow2-0.vercel.app**
3. Every future `git push` to `main` redeploys automatically.

### Step 5 — Post-deploy checklist

- Open https://flow2-0.vercel.app and confirm the title reads
  "Flow 2.0 — Free AI Video & Image Generator".
- **Register the first account** — it automatically becomes the site owner
  and unlocks the `/admin` dashboard (in that browser).
- Try a text-to-image generation, then a text-to-video generation, and
  confirm the 8-second clip plays and downloads as WebM.
- Submit `https://flow2-0.vercel.app/sitemap.xml` in
  [Google Search Console](https://search.google.com/search-console) so the
  site gets indexed.

## Troubleshooting

- **Build fails on Vercel:** check the build log. This project has no
  `file:` dependencies and no server code, so a failure is almost always
  a Vercel settings issue — confirm Build Command is `npm run build` and
  Output Directory is `dist` (both are also set in `vercel.json`).
- **Wrong subdomain:** the Vercel *project name* controls the subdomain —
  rename the project to `flow2-0` in Vercel → Settings → General.
- **SPA routes 404 on Vercel:** make sure the repo-root `vercel.json` was
  pushed; it contains the `/studio` and `/admin` rewrites.
- **Images don't generate:** the free Pollinations API must be reachable
  from the visitor's browser. If it is down, generation fails with a clear
  error — nothing is charged, and no credits are consumed for images.
- **Video export doesn't work:** WebM export needs `MediaRecorder` and
  `canvas.captureStream` (all modern Chrome/Edge/Firefox/Safari). The clip
  still plays in the preview even when export is unsupported.
- **"My account is gone":** accounts live in browser localStorage only.
  A different browser, device, or cleared data means a fresh start — this
  is by design in this free, serverless version.
